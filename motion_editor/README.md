# Robi モーションエディタ

robiフォルダから起動：

```bash
python3 motion_editor/robi_gui.py
```

必要なライブラリ：`python3 -m pip install -r motion_editor/requirements.txt`
ファーム：`robi_motion/robi_motion.ino`（元のファームと同一）。

- モーション名・動作説明はメイン画面で入力し、「全体を保存」で保存。
- 姿勢行を1行選択し、「共通状態を管理」から追加・名前変更・削除・編集。
- 共通状態は `common_states.json` に自動保存。共有時はこのファイルをコピー。
- 開始／終了状態と移動時間を選び、「反映」で先頭／末尾に追加。再反映では置換。
- 共通状態の編集では、反映済みフレームは変化しません。
- 「選択行を保存」では開始／終了状態の参照を外します。
- 保存JSONのメタデータを読み込むときは「新規」から取り込みます。
- トルクは全20軸ON/OFFのみ。下半身だけのOFFは未対応。

詳細資料・テスト・サンプルは `../temp/motion_editor/` に退避しています。

## モーションプレーヤー

画面上部の「モーションプレーヤー」で別ウィンドウを開きます。
初期フォルダは `motion_editor/motions/`。「フォルダを開く」で任意のフォルダに切り替えられます。

- クリック：モーション名・説明・フレーム数・移動／待機時間・開始／終了状態を表示。
- ダブルクリック、または「選んだモーションを再生」：ファイルの全フレームを実機再生。
- 「エディタで開く」：別のエディタで開いて編集・別名保存。元の編集中の内容は保持。
- 「更新」：保存したファイルやフォルダの変更を一覧へ反映。
- 「停止・トルクOFF」：再生停止と全軸トルクOFF。

実機の接続とトルクONは元のメイン画面の「接続・実機」で操作します。
プレーヤーはフォルダ直下のJSONを表示し、再生時に最新の内容を読み込みます。
実機再生・音声・リミット検証は既存エディタと共通です。ファーム変更は不要です。
