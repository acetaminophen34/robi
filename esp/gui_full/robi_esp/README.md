# ポーズ・LED統合コントローラー

1. Arduino IDEで `robi_esp.ino` を開き、使用中のESP32-S3のボード・ポート設定で書き込む。
2. `esp` ディレクトリで `python3 robi_gui.py` を起動する（PyQt5、pyserialが必要）。
3. 上部のポートを選択して接続する。接続は両タブ共通。
4. ポーズ: 全身 TORQUE ON → 姿勢編集 → 全身の姿勢を送信。
5. LED: 左右のRGBと口の明るさを設定 → LEDに反映。自動送信も選択可能。

サーボUART: TX GPIO43 / RX GPIO44 / 方向制御 GPIO1 / 115200 baud。
LED I2C: SDA GPIO42 / SCL GPIO41 / address 0x04 / 100 kHz。
サーボはカスタムPCBの配線、LEDは `head/LED_gui/LED_gui.ino` のI2C設定を使用。
GPIO42/41は未使用のSD用ピン定義と重なるため、この構成ではSD SPIとの同時使用は不可。
LEDのUART用GPIO17/18は使用しない。
サーボの角度制限はスケッチの `limits` に定義。

GUIは `robi_gui.py` 単体で動作する（PyQt5、pyserialは必要）。
他のプロジェクトファイル・フォルダは読み込まない。任意のフォルダから起動可能。
統合GUI使用中は他のGUI・シリアルモニターから同じポートを開かないこと。
接続・タブ切替だけでは姿勢やLED値を自動送信しない。
起動時はLED消灯。サーボへの自動移動・トルクONは行わない。
全身TORQUE OFFはID2〜21が対象、LEDは別の全消灯ボタンで消灯する。
切断時は最後に送った実機の状態を維持する。

GUIは各指示の完了応答を待つ。緊急OFFは未送信キューを破棄し即送信するが、
ESP32で実行中の処理は完了まで待つ（PREPAREは約0.44秒、全軸OFFは約1秒）。
完了応答はスケッチの処理完了を示し、サーボの到達位置の実測ではない。

## 現在角度と画面サイズ

現在角度の読み取りには、更新した `robi_esp.ino` を再度書き込む。
統合GUIは V2 スケッチの応答を確認する。
「現在角度を取得（全身）」または「自動更新」で ID2〜21 の実測角度を表示。
自動更新は通信が空いている時に1軸ずつ取得し、全軸一巡は約4秒。
取得に成功した軸の指定角度とプレビューモデルにも反映する。反映だけでは移動指示は送信しない。
自動更新中は編集中の指定角度も取得値で上書きする。応答なしの軸はモデルの角度を維持する。値には取得からの経過時間を表示し、
5秒を超えると古い値と明示する。無応答はNA、切断時は表示を未取得へ戻す。
読み取りにはRX GPIO44および方向制御GPIO1への応答経路が必要。

サーボ状態取得は `STATUS,id`。応答は `STATUS,id,degree` または `STATUS,id,NA`、
続いて `OK,STATUS`。現在角度2バイトの0x0F直接要求を使用し、失敗時には0x09要求で再取得する。各試行は最大100ms待つ。
失敗時は `STATUS_RX,id,試行番号,受信バイト数,16進データ` をログへ出力し、
リターンパケットのID・アドレス0x2A・データ長・チェックサムを検証する。
参考: https://www.rc.futaba.co.jp/downloads/shop/WCI00000307N2511071447xdvub.pdf?mode=view

ウィンドウは画面に合わせた初期サイズで起動し、サイズ変更可能。
ポーズタブは左にモデル、右に全身20軸の指定角度・現在角度を配置し、必要に応じてスクロール可能。
中央の仕切りをドラッグして左右の幅を変更可能。通信ログは「通信ログを表示」で開閉する。

## GUIとの通信仕様

起動時および `PING` に対して `ROBI_COMBINED_V2` を返す。これはGUIとの
通信プロトコルの識別子であり、PCBリビジョンとは独立している。
`MOVE`、`TORQUE`、`MAXTORQUE`、`PREPARE`、`STOP`、`STATUS` は
処理完了後に `OK,<コマンド名>` を返す（MOVEはIDと適用角度も付加）。
`LED,左R,左G,左B,右R,右G,右B,口` は7個の整数（0〜255）を受け付ける。
`LED` と `OFF` の成功応答はともに `OK,LED`。I2C通信失敗は `ERR,I2C`、
起動時のLED初期化失敗は `ERR,I2C_INIT` としてログに表示する。
GUIのMin/Maxに加えてESP側の `limits` で角度を制限する。
